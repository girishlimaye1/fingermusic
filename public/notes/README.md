# Musical Notes

Place MP3 files for each note here:
- do.mp3 (C4 - 261.63 Hz)
- re.mp3 (D4 - 293.66 Hz)
- mi.mp3 (E4 - 329.63 Hz)
- fa.mp3 (F4 - 349.23 Hz)
- so.mp3 (G4 - 392.00 Hz)
- la.mp3 (A4 - 440.00 Hz)
- ti.mp3 (B4 - 493.88 Hz)

The app will automatically generate tones using Web Audio API if these files are not present.
